HYPERTEXT TRANSFER PROTOCOL

HTTP is an application layer in the Internet Protocal Suite for distributed, collaborative, hypermedia infromation system. HTTP is request-response protocal in the client-server model

A transaction starts with a client submitting a request to the server, then the server attempts to satisfy the request and returns a response to the client that describes the dispostion of the request and optionally contains a requested resource such as an HTML document document or other content
