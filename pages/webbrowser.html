WEB BROWSER

A web browser, often abbreviated as browser, is an application for accessing websites. When a user requests a web page from a particular website, the browser retrieves its files from a web server and then displays the page on the user's screen. Browsers are used on a range of devices, including desktops, laptops, tablets, smartphones, smartwatches, smart televisions and consoles. The purpose of a web browser is to fetch content and display it on the user's device.

This process beings when the user inputs a URL inot the browser's address bar.
